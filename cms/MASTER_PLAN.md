# VIBELINK CMS 1.0.0-beta.1

Статус: восстановление после сбоя среды. Это ещё не выпуск для установки.

## Согласованные требования
- PHP 8.2+ и MySQL для Beget, один владелец.
- Существующие 18 страниц и адреса сохраняются; добавляется страница продуктов.
- Общие меню и подвал, дерево до трёх уровней, внешние HTTPS ссылки.
- Редактор HTML/CSS/JavaScript, простые шаблоны, черновик, публикация, история, изолированный предпросмотр.
- Вложения страниц, полный экспорт ZIP.
- Закрытое управление публичными файлами link, загрузка частями, замена без смены URL, корзина.
- Админский поддомен отдельного origin, HTTPS, обязательный TOTP, резервные коды, Argon2id, CSRF/Origin, ограничение попыток.
- Конфигурация, ключи, временные файлы и резервные копии вне public_html.

## Порядок выпуска
1. Восстановить миграцию и сохранить исходники в этой ветке.
2. Реализовать сервер и интерфейс, сохранять проверяемые этапы коммитами.
3. Повторно проверить восстановленную сборку. Старые результаты не считать проверкой нового кода.
4. Подготовить ZIP и два документа Word, сохранить комплект отдельно.
5. Устанавливать сначала на отдельную тестовую копию Beget. Основную ветку и production не менять.

Секреты, база владельца и клиентские медиа в GitHub не отправляются.
