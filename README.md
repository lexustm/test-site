# SFERA — demo website

Небольшой демонстрационный сайт из трёх страниц, опубликованный через GitHub Pages.

- `index.html` — главная
- `services.html` — услуги и этапы работы
- `contact.html` — демонстрационная интерактивная форма
- `css/style.css` — дизайн и адаптивность
- `js/main.js` — меню, анимации и интерактивность

Сайт закрыт от индексации метатегами `noindex` и файлом `robots.txt`.
