# VIBELINK

Аккуратно пересобранная версия исходного сайта digital-маркетолога Алексея.

Внешний вид, тексты, форма фотографии, фирменный курсор, движения фоновых элементов, карточек и остальные анимации сохранены по оригиналу. Изменена только внутренняя организация и небезопасная техническая часть.

## Структура

- `index.html` — разметка и тексты;
- `assets/css/main.css` — исходный дизайн, анимации и адаптивность;
- `assets/js/main.js` — навигация, 3D-наклоны карточек и консультант;
- `images/` — исходные изображения без замены и перерисовки;
- `.htaccess` — защитные заголовки, сжатие и кеширование для Beget;
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest` — SEO и системные файлы.

## Что исправлено внутри

- удалены блокировка правой кнопки мыши, запрет копирования и код подмены страницы при открытии инструментов разработчика;
- убраны встроенные обработчики событий из HTML;
- сообщения консультанта создаются безопасно и не выполняют введённый HTML-код;
- консультант ничего не отправляет и не сохраняет, а предлагает продолжить разговор в Telegram;
- добавлены клавиатурное управление, фокус и режим уменьшенной анимации.

## Публикация на Beget

1. Сделайте резервную копию текущего сайта.
2. Сохраните старую папку `link`, если прямые ссылки на размещённые там видео и аудио ещё используются.
3. Загрузите содержимое проекта в `public_html`.
4. Не удаляйте `.htaccess`.
5. После публикации проверьте главную страницу, Telegram, ВКонтакте и консультант.

Папка `link` намеренно не включена: главная страница её не использует, а один из находящихся там файлов — `link/sg/cat.mp4` — повреждён.
