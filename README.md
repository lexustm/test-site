# VIBELINK

Пересобранная версия сайта digital-маркетолога Алексея.

## Структура

- `index.html` — семантическая разметка и тексты;
- `assets/css/main.css` — дизайн и адаптивность;
- `assets/js/main.js` — навигация, анимации и консультант;
- `assets/images/` — оптимизированные изображения;
- `.htaccess` — защитные заголовки, сжатие и кеширование для Beget;
- `robots.txt`, `sitemap.xml`, `manifest.webmanifest` — SEO и системные файлы.

## Публикация на Beget

1. Сделайте резервную копию текущего сайта.
2. Сохраните старую папку `link`, если размещённые в ней прямые ссылки на видео и аудио ещё используются.
3. Загрузите содержимое проекта в папку `public_html`.
4. Не удаляйте `.htaccess`: он отвечает за защитные HTTP-заголовки и кеширование.
5. После публикации проверьте главную страницу, ссылки Telegram/ВКонтакте и консультант.

Папка `link` из исходного архива намеренно не включена: она не используется главной страницей, содержит около 282 МБ отдельных медиафайлов, а `link/sg/cat.mp4` повреждён.

## Безопасность

Консультант работает только в браузере. Он не отправляет и не сохраняет сообщения, не использует API-ключи и не содержит серверной части. Внешний переход ведёт только на официальный Telegram-профиль `@smmtotal`.
